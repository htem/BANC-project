# `data/banc_annotations/` — per-version annotation snapshots + term lists

Holds the per-BANC-version cluster + UMAP assignment tables, the
annotation-terms spreadsheet, and the seed-group definitions.

## Layout

| Path | What it is |
| --- | --- |
| `v626/`, `v850/`, `v888/` | One subdir per BANC dataset materialisation. Each contains the per-version snapshots of the AN/DN UMAP + cluster CSV (`banc_neck_functional_classes.csv`), the effector UMAP + cluster CSV (`banc_efferent_functional_classes.csv`), and a per-neuron view of the AN/DN clusters (`banc_neck_functional_classes_by_neuron.csv`, v888 onwards). The active version is `v888/`; older snapshots stay around so we can re-run preprint-era analyses without re-pulling SeaTable. |
| `annotation_terms_list.xlsx`, `annotation_terms_list_251022.xlsx` | The frozen-as-of-date enumeration of every term used in the hierarchical taxonomy (`flow`, `super_class`, `cell_class`, `cell_sub_class`, plus auxiliary columns: `nerve`, `hemilineage`, `body_part_*`, `peripheral_target_type`, `cell_function*`). Underpins Supplementary Data 1. |
| `seeds.md` | Definitions of the seed groups (`seed_01`, `seed_02`, …) used by the influence calculator — i.e. how the source populations for each `query_influence()` run are constructed. |

## Provenance

`banc_neck_functional_classes.csv` is written by
`R/figures/panels_an_dn_umap.R` (the AN/DN PCA-UMAP + Marchenko-Pastur
hierarchical clustering described in Methods §"Clustering influence by
influence and connectivity"). `banc_efferent_functional_classes.csv` is
written by `R/figures/panels_efferent_umap.R`. The annotation-terms
xlsx is regenerated by `R/annotations/make_annotation_terms_spreadsheet.R`
from the live Codex export.

## Consumers

The `v888/` CSVs are read by basically every Fig. 3+ panel (cluster
labels + UMAP coordinates) and by `R/startup/banc-meta-live.R` (which
joins the cluster assignment back onto `banc.meta`). The older snapshots
are read by `R/annotations/rebuild_interactive_tools.R` (joins v626's
super_cluster history onto current neurons via the `root_626` column).
