# `data/braun_et_al/` — external reference data (Braun et al., 2024, *Nature*)

External published reference data from **Braun et al., 2024, *Nature***
(DOI [`10.1038/s41586-024-07523`](https://doi.org/10.1038/s41586-024-07523)) —
predicted DN behavioural functions inferred from direct DN-DN
connectivity in FAFB.

## Layout

| File | What it is |
| --- | --- |
| `41586_2024_7523_MOESM4_ESM.xlsx` | Supplementary Table 4 from the Braun et al. paper — DN cell types annotated with predicted behavioural functions and confidence scores. |

## Provenance

Downloaded as-is from the Nature article's supplementary materials.
Not modified, not regenerated by anything in this repo.

## Consumers

`R/figures/panels_an_dn_umap.R` reads the spreadsheet and joins the
predicted-function column onto the BANC PCA-UMAP to produce **ED Fig. 6c**
("PCA-UMAP coloured by Braun et al. predicted function"). The join key
is FAFB cell type, resolved via the BANC ↔ FAFB cell-type match in
`franken.meta`.
