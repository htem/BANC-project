# banc_swc_skeletons.zip

## Purpose

Per-neuron skeleton files for the BANC connectome at v888, in standard
SWC format. Each `<root_id>_l2.swc` represents one segment's skeleton
at the L2 chunked-graph resolution — fine enough to capture branching
structure and overall morphology, coarse enough to keep file size
manageable.

These skeletons are the morphological substrate behind every BANC-side
NBLAST score in the dataset and behind the cable-length numbers in
`banc_888_metrics.feather`. They are also the natural input for any
user-side morphology analysis or visualization.

## Provenance

Generated by **bancpipeline** at `banc/metrics/banc-calculate-skeletons.R`,
which calls the FlyWire `pcg_skel` Python pipeline
(https://github.com/CAVEconnectome/pcg_skel) over the BANC chunked-graph.
Skeletons are produced at the L2 level and written one-per-neuron in SWC
format via `nat::write.neuron.swc`. The ZIP archive is packaged from the
source GCS directory at upload time.

## Schema

Standard SWC format. Each row is one skeleton node:

```
PointNo Label X Y Z Radius Parent
```

with whitespace separators and `#` comments at the top. Coordinates are
in BANC voxel space (4 × 4 × 45 nm). All nodes carry `Label = 2`
(SWC's "axon" code), which is the pcg_skel default rather than a real
compartment assignment — true axon/dendrite splits live in
`banc_888_edgelist_split_v2.feather`, not in the SWC.

## Usage

In R via natverse:

```r
library(nat)
n <- read.neuron("720575941521131930_l2.swc")
plot3d(n)
```

In Python via navis:

```python
import navis
n = navis.read_swc("720575941521131930_l2.swc")
n.plot3d()
```

For a single neuron without downloading the ZIP, bancr's wrapper
`banc_skeleton(id)` fetches the SWC over the network.

## Related files

- `banc_888_meta.feather` — resolves each root ID to identity and
  annotations.
- `banc_888_metrics.feather` — pre-computed cable length, surface area
  and node count for each skeleton.
- `banc_neuron_meshes.zip` — full segmentation meshes for the same
  segments when higher-resolution morphology is needed.
- NBLAST feathers under `nblast/` (e.g. `banc_fafb_783_nblast.feather`)
  — pairwise morphology similarity derived from these skeletons.

## Notes

- The ZIP file is large. Stream-decompress if disk space is tight
  (`unzip -p` to stdout into a per-file consumer).
- Coverage is broad: an SWC exists for every BANC segment with an L2
  graph at v888, including small fragments and glia. For a clean
  proofread set, filter against `banc_888_meta.feather`
  (`proofread == TRUE` and `super_class != "glia"`) before processing.
- For the highest-resolution morphology, work from the segmentation
  meshes (`banc_neuron_meshes.zip`) instead. The L2 skeletons trade
  some detail for tractability.
