# banc_nt_prediction_v3_w_sizethresh_10_05042026.parquet

## Purpose

This is the **per-synapse neurotransmitter-classifier output** for the
v3 synapse snapshot. Each row is a single predicted presynaptic site,
identified by its CAVE synapse `id`, together with the classifier's
probability vector across the eight fast-acting neurotransmitter classes
(acetylcholine, dopamine, GABA, glutamate, histamine, octopamine,
serotonin, tyramine), an argmax label `predicted_nt`, and the value of
the argmax `probability`. The table is filtered to postsynaptic
detections of size at least 10 voxels, the v3-snapshot threshold.

The downstream master table `banc_888_synapses_v3_enriched.parquet`
joins this file by synapse `id`. The v3 synapse stack is not used in
the BANC paper figures (which are computed on v2), but is the
recommended starting point for new analyses that benefit from the
updated detector and classifier.

## Provenance

Generated by the BANC neurotransmitter-classifier pipeline (paper
Methods, "Neurotransmitter prediction"; code at
https://github.com/htem/synister_banc). The v3 model is a refresh of
the v2 3D ResNet-18 with additional BANC-centric training data; v2
was trained primarily on cutouts compiled from FAFB, MANC and
Hemibrain. The v3 synapse detector and classifier will be reported
in upcoming work; this deposit is provided so users can build
analyses on the current synapse stack.

Inference was run over all v3 synapse detections with postsynapse
size at least 10 voxels and exported on 2026-04-05. Probabilities are
emitted as half-precision floats (`halffloat`) to keep the file
compact; cast to `float32` on read if your downstream code is
sensitive to half-precision rounding.

## Schema

| column | dtype | description |
|---|---|---|
| `id` | int64 | Synapse identifier from the CAVE v3 synapse table. Joins to `id` in `banc_888_synapses_v3_enriched.parquet` and to `id` in `synapse_neuropil_lookup_v3.parquet`. |
| `acetylcholine` | halffloat | Classifier probability for acetylcholine, `[0, 1]`. |
| `dopamine` | halffloat | Classifier probability for dopamine. |
| `gaba` | halffloat | Classifier probability for GABA. |
| `glutamate` | halffloat | Classifier probability for glutamate. |
| `histamine` | halffloat | Classifier probability for histamine. |
| `octopamine` | halffloat | Classifier probability for octopamine. |
| `serotonin` | halffloat | Classifier probability for serotonin. |
| `tyramine` | halffloat | Classifier probability for tyramine. |
| `predicted_nt` | string | Argmax neurotransmitter label for the synapse. |
| `probability` | halffloat | Value of the argmax probability, i.e. the confidence of `predicted_nt`. |

## Usage

Predicate pushdown by synapse `id` or by `predicted_nt` is the natural
access pattern. From R via arrow:

```r
library(arrow); library(dplyr)
nt <- open_dataset("banc_nt_prediction_v3_w_sizethresh_10_05042026.parquet") %>%
  filter(predicted_nt == "glutamate", probability > 0.9) %>%
  collect()
```

From Python:

```python
import pyarrow.dataset as ds
nt = ds.dataset("banc_nt_prediction_v3_w_sizethresh_10_05042026.parquet").to_table(
    columns=["id", "predicted_nt", "probability"]
).to_pandas()
```

To aggregate to a neuron-level prediction, join `id` to
`banc_888_synapses_v3_enriched.parquet` for the `pre_root_id`, sum the
eight probability columns over `pre_root_id` and take the argmax.

## Related files

- `banc_888_synapses_v3_enriched.parquet` — the v3 enriched synapse
  table, which receives this file's predictions by synapse `id`.
- `banc_888_synapses_v2_enriched.parquet` — the v2 counterpart; uses
  `banc_nt_prediction_w_sizethresh_5_11102025.parquet` as its
  classifier source.
- `synapses/v3.0/synapse_neuropil_lookup_v3.parquet` — per-synapse
  neuropil assignment for the v3 snapshot.
- `banc_888_meta.feather` — per-neuron table; its
  `neurotransmitter_predicted` / `neurotransmitter_score` are aggregated
  from the **v2** classifier output, not this one. v3 neuron-level
  predictions are not yet provided as a compiled table.

## Notes

- **v2 versus v3.** The v3 detector recovers detections missed by the
  v2 model; despite the stricter `>= 10` cutoff, v3 has roughly 37%
  more rows than v2 (259M versus 189M). The v3 classifier has an
  updated training set with more BANC-centric data. v2 uses a
  postsynapse size cutoff of `>= 5` voxels and is the snapshot used
  throughout the paper. Treat v2 and v3 as separate synapse
  universes, not interchangeable — synapse `id`s do not match across
  versions.
- **`id` is `int64` here**; cast on join with the v3 enriched parquet
  (`large_string`) or with `synapse_neuropil_lookup_v3.parquet`
  (`large_string`) as needed.
- **Probabilities sum to 1 per row** within half-precision rounding.
- **Serotonin** over-calling on peptidergic neurons applies here as
  in v2; treat low-confidence serotonin predictions with care.
- **Date in filename** (`05042026`) is the export date, 2026-04-05.
