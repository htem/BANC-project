# banc_neuropil_meshes.zip

## Purpose

The set of named neuropil-region meshes used as anatomical context in
every 3D BANC figure — antennal lobe, mushroom body, lobula, lobula
plate, central complex sub-regions, the leg neuromeres, and so on. Each
mesh is a watertight triangle surface in BANC space that callers can
overlay on neuron renderings to give the viewer a sense of location.

The same names appear in the `neuropil` column of the per-synapse tables
and in the `region` column of `banc_888_meta.feather`, so this archive
also serves as the canonical 3D realization of those labels.

## Provenance

Built by the BANC neuropil-surface pipeline described in the paper
Methods section "BANC neuropil mesh generation":

1. Sample every 500th synapse from the BANC synapse table; convert to
   nanometers.
2. Apply a k-nearest-neighbor density filter (≥ 10 neighbors within
   10 μm).
3. Fit a 3D alpha-shape (α = 7.5 μm), convert to triangle mesh,
   decimate to ~25 % of faces, Taubin-smooth (10 iterations), clean
   degenerate/isolated facets, and remesh small gaps until each
   region is closed.
4. Split the result at the neck to separate brain and VNC components.
5. Register neuropil meshes defined in other works (central brain,
   VNC) into BANC space using the elastix registrations also
   deposited here.

The output is one OBJ per region, plus aggregate brain and VNC outer
surfaces. The same surfaces are also served on GCS as a Neuroglancer
precomputed-mesh layer (with integer segment IDs) for live viewers;
the Dataverse ZIP carries the OBJ form.

## Contents

Not tabular. The ZIP unpacks to one Wavefront `.obj` (`v`, `vn`, `f`
records) per neuropil region, with file names following the neuropil
naming convention used in the `region` / `neuropil` columns of the
BANC tables.

## Usage

In R via natverse:

```r
library(nat)
mb <- read.neuron.obj("MB_CA_R.obj")
plot3d(mb, alpha = 0.2, col = "grey")
```

In Python via trimesh:

```python
import trimesh
mb = trimesh.load("MB_CA_R.obj")
mb.show()
```

## Notes

- Coordinates are in BANC voxel space (4 × 4 × 45 nm), like the rest
  of this dataset.
- Region boundaries are derived from synapse density and so do not
  perfectly match the membrane-based parcellations used in other
  Drosophila atlases. They are intended as a working approximation
  for visualization; for atlas-quality boundaries, use the JRC2018
  parcellation transformed into BANC space via the registration ZIPs.
- The brain and VNC outer surfaces are intentionally separated at the
  neck; do not expect a single closed CNS surface.
- The live precomputed-mesh layer on GCS encodes regions by integer
  segment ID. The Dataverse OBJ ZIP carries human-readable region
  names; use the ZIP for offline / scripted access and the live
  layer for Neuroglancer overlays.
- **Tissue-outline mesh and the z-scaling caveat.** The whole-CNS
  outer surface ("tissue outline") was originally generated by Nico
  from the segmentation mask and lives as **segid 1** in
  `precomputed://gs://zetta_lee_fly_cns_001_kisuk/final/v2/volume_meshes`.
  That original mesh needs to be **scaled in Z by ×0.9462** to align
  with the BANC EM image and segmentation — a one-off mismatch from
  the way the upstream pipeline built it. A pre-scaled copy (z·0.9462
  applied) is also segid 1 in the Lee-lab `region_outlines/` layer
  this ZIP is built from, so users of the deposited OBJs do not need
  to apply the correction themselves. The note is included here for
  users who want to start from the original Zetta source.
