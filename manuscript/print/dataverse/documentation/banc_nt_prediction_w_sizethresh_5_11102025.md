# banc_nt_prediction_w_sizethresh_5_11102025.parquet

## Purpose

This is the **per-synapse neurotransmitter-classifier output** for the
v2 synapse snapshot. Each row is a single predicted presynaptic site,
identified by its CAVE synapse `id`, together with the classifier's
probability vector across the eight fast-acting neurotransmitter classes
(acetylcholine, dopamine, GABA, glutamate, histamine, octopamine,
serotonin, tyramine), an argmax label `predicted_nt`, and the value of
the argmax `probability`. The table is filtered to postsynaptic
detections of size at least 5 voxels — the threshold the paper adopts
for all neuron-to-neuron and neurochemical analyses (see Methods,
"Synapse detection evaluation" for the size-threshold justification;
"Neurotransmitter prediction" for the classifier itself).

The downstream master table `banc_888_synapses_v2_enriched.parquet`
joins this file by synapse `id` to populate its eight per-NT probability
columns plus `syn_top_nt` / `syn_top_p`. Neuron-level predictions in
`banc_888_meta.feather` (`neurotransmitter_predicted`,
`neurotransmitter_score`) are obtained by summing per-class
probabilities over a neuron's presynaptic sites and taking the argmax.

## Provenance

Generated by the BANC neurotransmitter-classifier pipeline (paper
Methods, "Neurotransmitter prediction"; code at
https://github.com/htem/synister_banc). The classifier is a 3D
ResNet-18 trained on 640 x 640 x 630 nm EM cutouts centred on
presynaptic sites, using ground-truth labels compiled from FAFB, MANC
and Hemibrain across 4,356 cell types. The training approach follows
Eckstein et al. (2024), but the model itself was trained on BANC EM
cutouts.

Inference was run over all v2 synapse detections with postsynapse size
at least 5 voxels and exported on 2025-10-11. Probabilities are emitted
as half-precision floats (`halffloat`) to keep the file under 4 GB;
cast to `float32` on read if your downstream code is sensitive to
half-precision rounding.

## Schema

| column | dtype | description |
|---|---|---|
| `id` | int64 | Synapse identifier from the CAVE v2 synapse table. Joins to `id` in `banc_888_synapses_v2_enriched.parquet` and to `id` in `synapse_neuropil_lookup_v2.parquet`. |
| `acetylcholine` | halffloat | Classifier probability for acetylcholine, `[0, 1]`. |
| `dopamine` | halffloat | Classifier probability for dopamine. |
| `gaba` | halffloat | Classifier probability for GABA. |
| `glutamate` | halffloat | Classifier probability for glutamate. |
| `histamine` | halffloat | Classifier probability for histamine. |
| `octopamine` | halffloat | Classifier probability for octopamine. |
| `serotonin` | halffloat | Classifier probability for serotonin. |
| `tyramine` | halffloat | Classifier probability for tyramine. |
| `predicted_nt` | string | Argmax neurotransmitter label for the synapse. |
| `probability` | halffloat | Value of the argmax probability, i.e. the confidence of `predicted_nt`. |

## Usage

Predicate pushdown by synapse `id` or by `predicted_nt` is the natural
access pattern. From R via arrow:

```r
library(arrow); library(dplyr)
nt <- open_dataset("banc_nt_prediction_w_sizethresh_5_11102025.parquet") %>%
  filter(predicted_nt == "gaba", probability > 0.9) %>%
  collect()
```

From Python:

```python
import pyarrow.dataset as ds
nt = ds.dataset("banc_nt_prediction_w_sizethresh_5_11102025.parquet").to_table(
    columns=["id", "predicted_nt", "probability"]
).to_pandas()
```

To aggregate to a neuron-level prediction, join `id` to
`banc_888_synapses_v2_enriched.parquet` for the `pre_root_id`, then sum
the eight probability columns over `pre_root_id` and take the argmax.
For most users `banc_888_meta.feather` already carries the resulting
`neurotransmitter_predicted` / `neurotransmitter_score`.

## Related files

- `banc_888_synapses_v2_enriched.parquet` — joins this file's per-synapse
  predictions into the enriched v2 synapse table (eight probability
  columns + `syn_top_nt` + `syn_top_p`).
- `banc_888_synapses_v3_enriched.parquet` — the v3 counterpart; uses
  `banc_nt_prediction_v3_w_sizethresh_10_05042026.parquet` as its
  classifier source.
- `synapses/v2.0/synapse_neuropil_lookup_v2.parquet` — per-synapse
  neuropil assignment, joinable by the same `id`.
- `banc_888_meta.feather` — per-neuron table carrying
  `neurotransmitter_predicted` / `neurotransmitter_score` aggregated
  from this file.

## Notes

- **v2 versus v3.** The v2 snapshot uses a postsynapse size cutoff of
  `>= 5` voxels and the classifier described in the paper Methods.
  The v3 snapshot
  (`banc_nt_prediction_v3_w_sizethresh_10_05042026.parquet`) uses a
  stricter `>= 10` cutoff and an updated classifier, and despite the
  stricter cutoff contains roughly 37% more rows than v2 (the v3
  detector recovers many detections the v2 model missed). v2 and v3
  synapse `id`s are not interchangeable. The paper uses v2 throughout.
- **`id` is `int64` here** (not the `string` `id` in
  `banc_888_synapses_v2_enriched.parquet`). Cast to string on join, or
  cast the enriched file's `id` to `int64`, whichever is cheaper for
  your workflow.
- **Probabilities sum to 1 per row** within half-precision rounding —
  this is by construction of the softmax classifier head.
- **Serotonin** predictions in particular are over-called: the classifier
  tends to assign serotonin to peptidergic neurons that lack a clearer
  signal (paper Methods, "Neurotransmitter prediction").
- **Date in filename** (`11102025`) is the export date, 2025-10-11.
