# Dataset Description for the BANC v888 Harvard Dataverse

This file holds the **dataset-level** description posted to the Dataverse
citation block (the `dsDescriptionValue` field via the Dataverse API).
Dataverse renders the description in plain text with paragraph breaks
but does not reliably render markdown lists or tables, so the text below
is prose-formatted.

---

This deposit is a stable, DOI-citable snapshot of BANC — a synapse-resolution electron-microscopy reconstruction of the central nervous system of one adult female *Drosophila melanogaster*, spanning the brain and ventral nerve cord (VNC). It accompanies the published paper *Distributed control circuits across a brain-and-cord connectome* (Bates, Phelps, Kim, Yang et al., 2026) and contains ~188 000 neurons, ~199 million v3 synapses, the derived analysis-ready tables, and the code that produced them. The snapshot is pinned to CAVE materialization **v888**, snapshot date **2026-04-16** — the version of record cited in the paper.

This Dataverse is one of several complementary resources. The aligned EM image data lives on BossDB (https://bossdb.org/project/bates_phelps_kim_yang2025, DOI:10.60533/boss-2025-941r) — the volumetric source from which the segmentation was traced. The live, evolving reconstruction is browsable through FlyWire Codex (https://codex.flywire.ai/banc) and the BANC portal (https://banc.community), and accessible programmatically through CAVE, the Connectome Annotation Versioning Engine (https://global.daf-apis.com), at any materialization. The bulk-data source bucket is `gs://lee-lab_brain-and-nerve-cord-fly-connectome/`, from which this deposit was assembled and which carries the same folder layout. This Harvard Dataverse deposit is the static, citable snapshot at v888; use it for citation and for reproducing the paper's analyses, and use Codex, CAVE or the GCS bucket for ongoing work.

For data that is too large to mirror to Dataverse, we list the upstream GCS sources here so users can reach them directly. The aligned EM image volume is also distributed as precomputed Neuroglancer layers: full 4 nm resolution slicewise at `gs://leelab_fly_cns/fine_alignment/4nm` and at the HMS o2 mirror `/n/data3_vast/hms/neurobio/htem/temcagt/datasets/BANC/EM-4nm`; 8 nm sharded variants at `precomputed://gs://zetta_lee_fly_cns_001_alignment/v1_sharded` (jpeg-quality 90, 256×256×16 chunks) and at the regional mirrors `precomputed://gs://seunglab_lee_fly_cns_001_alignment/aligned/v0` (US east, jpeg-quality 75, 128×128×16 chunks) and `precomputed://gs://seunglab_lee_fly_cns_001_alignment_asia/aligned/v0` (Asia). The cell segmentation is served in three tiers: supervoxels at `precomputed://gs://zetta_lee_fly_cns_001_segmentation/v1_sharded`; flat (agglomerated but not proofreadable) at `precomputed://gs://zetta_lee_fly_cns_001_kisuk/final/v2/seg_semantic_split_membrane`; and the editable, proofread chunked-graph version at `graphene://middleauth+https://cave.fanc-fly.com/segmentation/table/wclee_fly_cns_001` — this last is the one served through CAVE and Codex and is the source of the per-neuron `root_id` values in this deposit. Earlier CAVE materialisation table dumps remain available at `gs://brain-and-nerve-cord_exports/` for users reproducing preprint-era analyses.

The deposit contains per-neuron metadata (soma position, proofreading status, the cell-type hierarchy super_class → cell_class → cell_sub_class → cell_type, functional and body-part annotations, AN/DN cluster and CNS-network membership, and cross-dataset matches to FAFB, MANC, FANC, maleCNS and Hemibrain); per-synapse tables at two synapse-prediction snapshots — v2 (size ≥ 5), the snapshot used by Bates, Phelps, Kim, Yang et al., 2026 in every figure and quantitative analysis, and v3 (size ≥ 10), the newer detector recommended for analyses building on the updated synapse model — enriched with neuropil, region and side plus the per-synapse neurotransmitter-classifier output; neuron-to-neuron and compartment-to-compartment connectivity edgelists rolled up from each synapse snapshot; NBLAST tables for cross-dataset morphological similarity against FAFB v783, MANC v1.2.1, FANC v1116, maleCNS v0.9 and Hemibrain v1.2.1, plus within-BANC and mirror-BANC matrices; adjusted-influence scores under the linear-dynamical-systems model described in the paper Methods, both as sub-class roll-ups and as the full 287 GB all-to-all matrix sharded by source neuron, computed with the `ConnectomeInfluenceCalculator` Python package (Ajabi & Drugowitsch; DOI:10.5281/ZENODO.15999930); the upstream CAVE annotation tables that feed the per-neuron metadata; per-neuron morphology (SWC skeletons built with FlyWire's `pcg_skel`, full-resolution segmentation meshes, neuropil-region meshes, and color-depth MIPs in JRC2018U space for NeuronBridge search); anatomical scaffolds (BANC-to-JRC2018F and BANC-to-JRC2018VNCF elastix registrations, the source and target template volumes, and an X-ray microCT scan of the BANC fly for whole-body context); pre-EM rBIas tethered-walking recordings of the BANC fly; snapshot ZIPs of the analysis stack (bancr, bancpipeline, BANC-project, influencer, ConnectomeInfluenceCalculator, nat.ggplot, the-BANC-fly-connectome — which also bundles the Slack-based annotation aide "banc-bot" at slackbots/annotation_bot.py, see https://blog.flywire.ai/2024/12/20/banc-bot-guide/ — fly_connectome_data_tutorial, drosophila_neuropeptides, drosophila_neurotransmitters); and front matter — author list and affiliations, the BibTeX bibliography, BANC fly-volume problem-region bounding boxes, and the Neuroglancer state JSONs behind every paper figure (2026a tag).

Neurons are tracked in CAVE: every neuron at v888 has a unique 64-bit integer `root_id`. A `position` (voxel) maps to a `supervoxel_id` (a small, uneditable collection of voxels), which in turn maps to a `root_id` (the editable collection of supervoxels comprising the current neuron). Synapses carry their own `id`. Columns prefixed `pt_` carry information attached at a user-placed CAVE point. The deposit retains earlier materialization root IDs (`root_626`, the preprint version; `root_850`, an interim materialization) as join keys for users coming from preprint-era resources.

Cite both the paper and this deposit. Several internal code archives carry their own preferred citations (Zenodo DOIs for the influence calculator); see the per-file documentation. This deposit is intentionally static. The live BANC continues to evolve — proofreading and annotations are ongoing. For the most up-to-date version of any record, use Codex or the GCS bucket. For the version of record cited in the paper, use this deposit.
